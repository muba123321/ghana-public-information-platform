# GPIP Government Performance & History — Roadmap

Spec: `docs/superpowers/specs/2026-11-09-gpip-government-performance-design.md`

The spec is delivered as four plans, each ending in working, tested, deployable software. Each
plan maps to a GitHub milestone. Plans 2–4 are written in detail only when the previous plan is
merged, so they build on real code rather than guesses.

| # | Plan / milestone | Delivers | Spec sections |
|---|---|---|---|
| 1 | **Foundation** | Monorepo, CI, AGENTS.md, `core` period/attribution/baseline rules, Postgres schema for parties/people/administrations/leaders/sources/sectors/institutions/lineage/change log, verified 1957→present administration seed, public site shell with administration directory + profile, footer notice and Data notice page | §3 goals 1–3, §5 political + institutions + sources, §6 areas 1–2 (basic), §11 items 1–2, 9, 10 |
| 2 | **Indicators** | Indicator/observation/target/context-event schema with vintages, sources and `estimate_type`; ingest pipeline + World Bank and IMF adapters; scheduled GitHub Action; indicator pages with ECharts administration bands, context events, table alternative and CSV; public API v1 for indicators | §3 goals 5–6, §4 API path, §5 indicators, §6 areas 4, 8, §11 items 3, 6, 7 |
| 3 | **Commitments & review** | Commitment, budget (`allocated/released/spent`), stewardship, progress-update and editorial-note schema; review queue + `/admin` with Auth.js allowlist; Claude document extractor writing to the queue; R2 document archive; public change log; commitment tracker, outstanding commitments, ministry history; pilot commitments | §3 goal 4, §4 AI path, §5 commitments + editorial, §6 areas 3, 6, 7, 9, §11 items 4, 5, 7 |
| 4 | **Compare & launch** | `tenureSummary` (average + start-to-end change, coverage) in `core`; Compare interface; full administration profiles; methodology page; neutral palette; accessibility & performance audit; Vercel + Neon + R2 production deploy; lawyer-review checklist for the disclaimer | §3 goals 7–8, §6 areas 2, 5, §7, §8 perf/a11y, §10 hosting, §11 item 8 |

Parallel work for Codex (after Plan 2's pipeline exists): additional source adapters — GSS
StatsBank, Bank of Ghana, AfDB, WHO GHO, UNESCO UIS — each a self-contained issue.
